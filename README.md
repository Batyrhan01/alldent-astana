# All Dent, стоматология в Астане

Одностраничный сайт для стоматологии All Dent (ул. Кайым Мухамедханов, 6а).

Что есть на странице: услуги, лечение детей во сне под севораном по шагам, фото пациентов до и после с ползунком, врачи, отзывы из 2ГИС, частые вопросы, карта и форма записи, которая открывает WhatsApp клиники.

Сайт сделан на чистом HTML и CSS, без сборки. Все тексты в `index.html`, фото в папке `img`.
